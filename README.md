## 📚 О проекте

Этот репозиторий содержит все мои лабораторные работы, выполненные в рамках первого курса по дисциплине **«Язык программирования Python»**. Здесь собраны решения различных задач — от базовых конструкций до более сложных алгоритмов и объектно-ориентированного программирования.

Все работы структурированы по номерам, что позволяет легко ориентироваться в пройденных темах и отслеживать прогресс.

## 🚀 Как запустить

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/leonidpoezzhaev/Python-Lab-Works.git
   cd Python-Lab-Works
   ```

2. **Перейдите в папку нужной работы:**
   ```bash
   cd "№1"
   ```

3. **Запустите Python-скрипт:**
   ```bash
   python 1.py
   ```
